# アセンブラ

PlusPim のアセンブラの仕様を示す．

## 失敗時の挙動

### コマンドライン引数 `--strict` がある場合

パースできない行がある場合はエラーとなる．

### ない場合

パースできない行は捨てられ，警告を出力する．

## 行の扱い

- `#` 以降はコメントとして除去する．

## セグメント

| 指令     | 開始アドレス |
| -------- | ------------ |
| `.text`  | `0x00400000` |
| `.ktext` | `0x80000180` |
| `.data`  | `0x10000000` |

- 最初の指令より前の行はテキストセグメントとして扱う
  - 警告を出力する

## ラベル

- 同名のラベルは警告を出して後の定義で上書きすされる．
  - データセグメントのラベルはテキストセグメントより優先される
  - 警告を出力する
- 未定義ラベルへの分岐とジャンプは実行時に `0x00000000` へ飛ぶ．
  - `la` の未定義ラベルはパース失敗になる

- `.globl`か`.global` で宣言していないラベルは，別のファイルから参照できない

### レジスタ

- `$` に続けて名前(`$zero`，`$at`，`$v0`-`$v1`，`$a0`-`$a3`，`$t0`-`$t9`，`$s0`-`$s7`，`$k0`-`$k1`，`$gp`，`$sp`，`$fp`，`$ra`)か番号(`$0`-`$31`)を書く
- 名前は小文字のみ受け付ける(`$T0` は不可)．番号は先頭に0を付けない(`$08` は不可)．`$32` 以上は不可
- `mfc0`/`mtc0` の CP0 レジスタは番号(`$0`-`$31`)のみ受け付ける

## 複数ファイル

- ファイルは指定順に，セグメントごとに前のファイルの末尾から続けて配置する
- データセグメントは前のファイルの末尾から整列せずに続ける
