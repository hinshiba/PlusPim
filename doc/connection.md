# DAP クライアントとの接続

`print_char` などの文字符号化方式依存を利用者のターミナル側で処理させるため，
デバッグ対象と標準入出力をつなげます．
そのため，DAPにおける通信を別の方法で行う必要があります．
PlusPim は次の2つの手法をサポートしています．

## TCP (推奨)

クライアントと PlusPim はTCPを用いて通信します．

標準ではこちらが選択されます．

## stdio (実験的)

DAP における `runInTerminal` を用いてクライアントに新しいターミナルを開くよう要求します．

`--stdio` オプションを付与するとこの動作となります．
