# CP0 操作命令の実行の振る舞い

## 対象とする CP0 レジスタ

| 番号     | 名前     | 読み出し値                                 | 書き込み時の扱い                              |
| -------- | -------- | ------------------------------------------ | --------------------------------------------- |
| 8        | BadVAddr | アドレス例外の実効アドレス．未設定なら `0` | 値をそのまま設定                              |
| 12       | Status   | EXL が1なら `0x2`，0なら `0x0`             | bit1 のみを EXL として反映し，他の bit は無視 |
| 13       | Cause    | ExcCode を2bit左シフトした値               | bit2〜6 のみを ExcCode として反映             |
| 14       | EPC      | 例外を起こした命令のアドレス               | 値をそのまま設定                              |
| 上記以外 | -        | ランタイムエラー                           | ランタイムエラー                              |


## 追加のパラメータ

- 実行モード: カーネルモード / ユーザーモード
- CP0 の状態
  - 初期値(ユーザーモード)
  - 例外発生直後(カーネルモード．各例外コード，`BadVAddr` あり/なし)
  - `eret` 後(ユーザーモードだが `Cause`/`EPC`/`BadVAddr` に値が残っている)
- CP0 レジスタ番号: 8，12，13，14 と，未対応の番号(`0`，`31` など)
- `eret` の EPC: 通常のアドレス / `eret` 自身のアドレス

## 追加の検証

### カーネルモードでの実行(正常系)

- `mfc0`
  - `rt` が上表の読み出し値と一致する
- `mtc0`
  - 指定した CP0 レジスタだけが上表の通りに変化する
  - Status に EXL=0 を書くとユーザーモードに戻る
- `eret`(PC を変更することに注意せよ)
  - PC が EPC の値になる(命令自身が PC を設定する)
  - EXL が0になりユーザーモードに戻る

### ユーザーモードでの実行(異常系)

- 命令の効果が一切現れない
- CP0 の `EPC` が命令アドレス，`Cause` が `CpU` になり，EXL が1になる
  - `eret` では，例外発生前の `EPC` が命令アドレスで上書きされる
- 実行モードがカーネルモードに遷移する

### CP0レジスタ番号で未対応の場合(異常系)

ランタイムエラー(未定)とする．
