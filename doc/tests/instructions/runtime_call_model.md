# ランタイムコールの振る舞いモデル

## テストの前提

- 標準入出力を使うため，`Console.SetIn`/`Console.SetOut` で差し替えて入力を与え，出力を検証する
- 標準入出力はプロセス全体で共有されるため，これらのテストは並列実行しないテストコレクションにまとめる

## 追加のパラメータ

- 実行モード: カーネルモード / ユーザーモード
- 機能番号 `$v0`: `1`(print_int)，`4`(print_string)，`5`(read_int)，`8`(read_string)，`10`(exit)，未知の番号(`0`，`11` など)
- 機能ごとの引数
  - print_int: `$a0` に [values.md](values.md) の代表値・境界値(負数を含む)
  - print_string: `$a0` が空文字列，ASCII，UTF-8 の多バイト文字を含む NUL 終端文字列を指す
  - read_int: 入力として正の数，負の数，`INT_MIN`/`INT_MAX`，範囲外の数，数値でない文字列，空行
  - read_string: `$a1` を `0`，`1`，入力長より小さい値，入力長と等しい値，入力長より大きい値にする

## 追加の検証

- ユーザーモードでの実行(異常系)
  - `CpU` 例外が発生する
  - 機能が実行されない
- print_int
  - `$a0` を符号付き10進数として出力する
  - `undo` は状態を変えない
- print_string
  - `$a0` から NUL の直前までを UTF-8 として出力する
  - `undo` は状態を変えない
- read_int
  - `$v0` が入力を32bit符号付き整数として解釈した値になる．解釈できない入力では `0` になる
  - `undo` で `$v0` が元に戻る
- read_string
  - `$a0` から最大 `$a1 - 1` バイトの入力と NUL を書き込む
    - `$a1 = 1` なら NUL のみ
    - `$a1 = 0` なら何も書き込まない
  - 入力が `$a1 - 1` バイトより短い場合も C# の例外を起こさない
  - 指定領域外のメモリが変化しない
  - `undo` で書き込んだ範囲のメモリが元に戻る
- exit
  - `IsTerminated` が `true` になる
  - `undo` で `false` に戻る
- 未知の番号
  - ランタイムエラー(未定)を発生させる
