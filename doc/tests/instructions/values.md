# テスト用パラメータリファレンス

原則としてすべての組を用いるものとする．

## レジスタエイリアスパターン

同レジスタ指定時の問題を検出する．

- 1レジスタ命令 (`r1`)
  - エイリアスなし
- 2レジスタ命令 (`r1, r2`)
  - `r1==r2`
  - エイリアスなし
- 3レジスタ命令 (`r1, r2, r3`)
  - `r1==r2`
  - `r1==r3`
  - `r2==r3`
  - `r1==r2==r3`
  - エイリアスなし

## ビットパターン

- 全0: `0x00000000`
- 全1: `0xffffffff`
- 交互パターン: `0xaaaaaaaa` / `0x55555555`
- バイト単位: `ff00ff00` / `0x00ff00ff`

## シフト量

### 即値

`0`, `1`, `15`, `16`, `31`

### レジスタ

更に，以下を追加する．

`32`，`0xff`，`0xffffffff`

## 32bit値

### 符号付き32bit値

#### 代表値

- 正の値: `0x000cafe0`
- 負の値: `0x800babe0`
- ゼロ: `0`

#### 境界値

符号付き32bit値 `[INT_MIN, INT_MAX]` と正負の境界．

- `0x80000000`
- `-1` (`0xffffffff`)
- `0`
- `1`
- `0x7fffffff`

#### 準境界値

境界値の隣接値．

- `0x7ffffffe`
- `0x80000001`

### 符号なし32bit値

符号付き32bit値を流用し，以下を追加する．

- 範囲の上限の隣接値: `0xfffffffe`

## 16bit値

### 符号付き16bit値

#### 代表値

- 正の値: `0x0afe`
- 負の値: `0xbabe`
- ゼロ: `0`

#### 境界値

符号付き16bit値 `[-32768, 32767]` と正負の境界．

- `0x8000` (`-32768`)
- `-1` (`0xffff`)
- `0`
- `1`
- `0x7fff` (`32767`)

#### 準境界値

境界値の隣接値．

- `0x7ffe`
- `0x8001`

### 符号なし16bit値

符号付き16bit値を流用し，以下を追加する．
拡張方式もそれで検証可能である．

- 範囲の上限の隣接値: `0xfffe`

## メモリアドレス

実効アドレス = ベースレジスタ値 + 符号拡張した16bitオフセットである．\

### 実効アドレス

#### アライメント

アクセスサイズごとに，実効アドレス下位ビットのパターンを網羅する．

- `00`
- `01`
- `10`
- `11`
