# ジャンプ命令の実行の振る舞い

## 追加のパラメータ

- コールスタックの状態(`jal`/`jr` のみ)
  - 空
  - `jal` 1回分のフレームが積まれている

## 追加の検証

- コールスタックの追加検証(`jal` のみ)
  - コールスタックに次の値を持ったフレームが1つ積まれる
    - ジャンプ前の PC
    - ジャンプ前のラベル
    - 変更前の各種レジスタ
  - 現在のラベルがジャンプ先のラベルになる
- コールスタックの削除検証(`jr` のみ)
  - コールスタックの先頭フレームの `PC + 4` がターゲットと一致する場合
    - そのフレームを取り出し，現在のラベルをフレームのラベルに戻す
    - `rs` が `$ra` かつ コールスタックが空で，フレームを取り出さなかった場合(`main` からの戻り)，`IsTerminated` が `true` になる
  - 一致しない場合はコールスタックを変更しない
