# 基本的命令の実行の振る舞い

## 検証する状態

- 汎用レジスタ32本
- 特殊なレジスタ: `HI`，`LO`，PC
- CP0の状態: (`BadVAddr`，`Status` の EXL，`Cause` の ExcCode，`EPC`)
- ランタイムの内部状態: `LastException`，`IsTerminated`
- デバッガの状態: コールスタックの深さ，現在のラベル
- 命令が読み書きしうる範囲のメモリ

## 共通

- 命令は PC を変更しない

## 正常系(例外を起こさない系)

- `execute` で例外が発生しない
- 結果を書き込むレジスタ以外のレジスタの値が変化しない
- 結果を書き込むレジスタの値が，命令の定義通りの計算結果と一致する
- `undo` で実行前の状態に戻る

## 異常系(例外が生じる系)

- `execute` で命令アドレスを含む例外をが発生する
- 引数となったレジスタの値が**すべて**変化しない
- CP0 の EPC が命令アドレス，Cause が 例外に対応したもの，EXL が1になる
- `undo` で例外発生前の状態に戻る

## 繰り返し実行

ループ内の命令は同じインスタンスが何度も実行されるため，`undo` 用の情報は実行ごとに積まれる．すべての命令について以下を1ケース以上確認する．

- 同じ命令インスタンスで，入力を変えながら `execute` を3回行う(例外を起こす命令では，正常系と異常系を混ぜる)
- その後 `undo` を3回行い，各 `undo` の後の状態が対応する `execute` の直前の状態と一致する
