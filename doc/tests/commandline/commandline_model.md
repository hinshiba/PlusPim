# コマンドラインの振る舞い

## パラメータ

- サブコマンド: なし，`debug`，`runtime`，未知の名前
- 共通オプション
  - 位置: サブコマンドの前，サブコマンドの直後，`<file>` の後ろ
  - 指定: あり，なし
- `--connect` / `--listen`
  - 指定: どちらもなし，片方，両方
  - サブコマンド: `debug`，`runtime`
  - 値: 正しい `ip:port`，書式の誤り，ポート 0，値なし
  - `ip`: IPv4，括弧付きの IPv6，括弧なしの IPv6，省略形の IPv4，DNS 名，`localhost`
- `<file>`
  - 個数: 0個，1個，複数
  - 名前: `-` で始まるもの，`./` を付けて `-` で始まるもの
- 未知のオプション: `--foo` のような `-` で始まるもの
- ヘルプ
  - 指定: `-h`，`--help`，`-?`
  - 位置: ルート，サブコマンド
- バージョン
  - 指定: `-V`，`--version`
  - 位置: ルート，サブコマンド

## 検証

### 共通

異常系
- サブコマンドなし
- 未知のサブコマンド
- 未知のオプション


### サブコマンド

正常系
- `./-`から始まるファイル 

異常系
- `<file>` が0個
- `--connect` と `--listen` の両方，またはどちらもなし

### 引数渡し

- `Files` は指定した順に並ぶ
- 共通オプションはどの位置に書いても機能する
- アクションの返した終了コードがそのまま返る

#### エラー発生時の挙動

- 終了コードが 0 でない
- メッセージの出力のみが行われる

#### ヘルプとバージョン

- 出力のみが行われる

正常系
- `--version` / `-V` は終了コード 0
- `--help` / `-h` / `-?` は終了コード 0
