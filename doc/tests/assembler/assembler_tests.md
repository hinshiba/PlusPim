# アセンブラ レベルテスト仕様

アセンブリのソースから命令列，シンボルテーブル，メモリイメージを作る前処理系を評価する．

仕様は [アセンブラ](../../assembler.md) を参照する．
実命令の実行は MIPS 命令 レベルテストで評価するため，ここでは扱わない．

期待するアドレスは `T` = `0x00400000`，`K` = `0x80000180`，`D` = `0x10000000` からの差で書く(例: `T+8`)．

空のチェックリストの項目は現時点では実装予定がない機能である．
これらのテストは免除する．

`要決定` は仕様が決まっていない項目である．
決まるまでテストしない．

## 検証する状態

- 展開後の命令数
- ラベルのアドレス
- 各命令の `SourceLine`
- メモリイメージと `Size`
- 警告ログ
- 実行後のレジスタとメモリ

## 共通の検証

以下は各モデルのすべての入力に適用する．

- パースに成功した行
  - 展開後の命令数が `GetInstructionCount` と一致する
  - 展開後のすべての命令の `SourceLine` がその行の1始まりの行番号になる
- パースに失敗した行
  - 命令を生成せず，`Parse failed for Instruction` の警告が1件出る
  - 他の行の処理は続き，読み込みは失敗しない
  - `GetInstructionCount` が0を返す(後続のラベルがずれない)
