# パースの振る舞い

## パラメータ

- 行の前処理
  - 行末のコメント
  - コメントのみの行
  - 空行
  - 文字列リテラル中の `#`
  - 改行コード
  - 空のファイル
- アセンブラ指令
- ラベル
  - インデント
  - `$` を含む
  - `:` の前の空白
  - 同名の重複
- 命令のオペランド
  - 区切り
  - レジスタの表記
  - 16bit 即値: [values.md](../instructions/values.md) の16bit値に加え，範囲の外側
  - シフト量: 範囲の内側と外側
  - メモリオペランドの書式
  - 分岐とジャンプのラベル
- データセグメント
  - 値を配置する

## 検証

### 行の前処理

- コメントが無視される
- コメントのみの行と空行は命令もラベルも生成しない
  - 後続の `SourceLine` は行を数えた値のままである
- CRLF は LF と同じ結果になる
- 空のファイルは何も生成せず，警告も出ない

### セグメント

- 指令なしで始まるファイルはテキストとして扱い，警告が発生する
- 同じセグメントを再開すると，前回の続きに配置される

### ラベル

- インデントや `$` を含むラベルが登録される
- `:` の前に空白があるとラベルにならない
- 1行に複数のラベルを書くと，すべて同じアドレスになる
- 重複した定義は後のものが残り，警告が発生する

### 命令のオペランド

#### 正常系

- 区切りは `,` の直後の空白の有無によらず成功する
- レジスタは小文字の名前と `$0` から `$31` の番号で指定できる
- 16bit 即値は `[-32768, 65535]` の範囲で成功する
  - 次の表記を受け付ける
    - 10進(`+`/`-`)
    - 16進(`0x`/`0X`)
- シフト量は `[0, 31]` の範囲で成功する
- メモリオペランドのオフセットは次を受け付ける
  - 10進
  - 16進

#### 異常系

- `,` を省いた空白区切りは失敗する
- 範囲外の番号(`$32` など)と未知の名前は失敗する
- 16bit 即値の範囲外の値とラベルは失敗する
- シフト量の範囲外の値は失敗する
- テキストセグメント中の `.align` と `.word` は命令を生成せず，警告を発生させる
  - `--strict` ではエラーになる


### データ指令の値

- 値はリトルエンディアンで書かれる
- 複数の値は指定順に連続する
- `.space 0` は何も確保せず警告を発生させる
- `.ascii` は NUL を付けず，`.asciiz` は NUL で終端する
  - 文字列は UTF-8 のバイト列で書かれる
  - 次のエスケープを解釈する
    - `\n`
    - `\t`
    - `\0`
    - `\\`
    - `\"`
  - 未知のエスケープは `\` と文字がそのまま書かれる
- 閉じる引用符がない文字列は警告を発生させる
- `.data` 中の命令は警告を発生させる
