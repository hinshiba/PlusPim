## 追加の検証

### 行の前処理

- コメントは無視され，文字列リテラル中の `#` は残る
- コメントのみの行と空行は命令もラベルも生成しない
  - 後続の `SourceLine` は行を数えた値のままである
- CRLF は LF と同じ結果になる
- タブ区切りでも1命令になる
- 空のファイルは何も生成せず，警告も出ない
  - 命令数0
  - データサイズ0

### セグメント

- 指令は大文字小文字によらず切り替わる
- 指令なしで始まるファイルはテキストとして扱い，`Segment type is not specified` の警告が1件出る
- 同じセグメントを再開すると，前回の続きに配置される
- `.ktext` の命令はカーネルテキストに入り，ユーザーテキストには入らない
- `.kdata` のラベルはカーネルデータのアドレスになり，データがメモリに書かれる
- [ ] 要決定: カーネルデータの開始アドレス(MARS は `0x90000000`)
- [ ] アドレス引数付きの指令 `.data 0x10010000`
  - [ ] 要決定: 引数を受け付けるか，警告を出して引数を無視するか

### ラベル

- インデントや `$` を含むラベルは登録される
- `:` の前に空白があるとラベルにならず，パース失敗の警告が出る
- 1行に複数のラベルを書くと，すべて同じアドレスになる
- ラベルの後にセグメント指令を書くと，ラベルは切り替え前のセグメントに属する
- 文字列中の `:` はラベルにならない
- 重複した定義は後のものが残り，`Duplicate label` の警告が1件出る
  - セグメントが異なる場合は，順序によらずデータ側が残る
- [x] 命令と同じ行のラベルは，その命令のアドレスになり，命令も生成される
- [x] データ指令と同じ行のラベルは，そのデータのアドレスになり，データも書かれる
- [ ] 要決定: ラベルの重複を警告ではなくエラーにするか

### 命令のオペランド

#### 正常系

- 区切りは `,` の直後の空白の有無によらず成功し，ニーモニックは大文字小文字を区別しない
- レジスタは小文字の名前と `$0` から `$31` の番号で指定でき，同じレジスタを指す
- 16bit 即値は `[-32768, 65535]` の範囲で成功する
  - ゼロ拡張の命令(`andi` など)も同じ規則とする
  - 次の表記を受け付ける
    - 10進
    - 16進(`0x`/`0X`)
    - `+` 付き
  - 成功した値は実行結果で確認する
- シフト量は `[0, 31]` の範囲で成功する
- メモリオペランドのオフセットは次を受け付ける
  - 10進
  - 16進
  - 負の値
- 未定義のラベルを指定してもパースは成功する
  - 実行時の振る舞いは命令のテストのジャンプ先で検証する
- テキストセグメント中の `.globl` は命令を生成せず，警告も出ない
- テキストセグメント中の `.align` と `.word` は命令を生成せず，`Directive ignored` の警告が出る
  - `--strict` ではエラーになる

#### 異常系

- `,` の前の空白と，`,` を省いた空白区切りは失敗する
- 範囲外の番号(`$32` など)と未知の名前は，レジスタを取るすべての形式で失敗する
  - `$s8` は別名がないため失敗する
  - 大文字の名前(`$T0`)と先頭に0を付けた番号(`$08`)は失敗する
  - `mfc0`/`mtc0` の CP0 レジスタに名前を書くと失敗する
- 16bit 即値の範囲外の値とラベルは失敗する
- シフト量の範囲外の値は失敗する
- ラベルのオフセットは失敗する
- [x] 括弧内の空白は受け付ける
- [x] オフセットの省略 `lw $t0, ($sp)` は `0($sp)` と同じになる
- [ ] 要決定: `,` の前の空白と，`,` を省いた空白区切りを受け付けるか
- [ ] 要決定: `$s8` を `$fp` の別名として受け付けるか
- [x] 要決定: テキストセグメント中の未対応の指令を黙って無視せず警告するか (警告する)

### データ指令の値

配置と整列は [アドレス配置の振る舞い](layout_model.md) で検証する．

- 値はリトルエンディアンで書かれ，複数の値は指定順に連続する
- 負の値は2の補数で書かれる
- 型に収まらない値は下位のビットが書かれ，警告は出ない
- `.space 0` は何も確保せず，`.space value cannot be negative or zero` の警告が出る
- `.ascii` は NUL を付けず，`.asciiz` は NUL で終端する
  - 文字列は UTF-8 のバイト列で書かれる
  - 次のエスケープを解釈する
    - `\n`
    - `\t`
    - `\0`
    - `\\`
    - `\"`
  - 未知のエスケープは `\` と文字がそのまま書かれる
- 閉じる引用符がない文字列は何も書かず，`Invalid string literal` の警告が出る
- 未知の指令は `Unknown data directive` の警告が出る
  - `.data` 中の `.globl` は指令として認識し，警告は出ない
- `.data` 中の命令は `Unexpected data segment content` の警告が出る
- [ ] 文字リテラル `.byte 'a'` は文字コードを書く
- [ ] 要決定: 型に収まらない値を警告するか
- [ ] 要決定: `.word` の10進数で `int` の範囲外(`4294967295`)を受け付けるか(16進の `0xFFFFFFFF` は受け付ける)
- [ ] 要決定: `.space` に16進数を受け付けるか
