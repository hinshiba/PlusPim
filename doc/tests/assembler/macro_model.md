# マクロの振る舞い

マクロ関連の指令はすべて未実装である．
空のチェックリストの項目は実装までテストを免除する．

## 追加の検証

### 未対応のマクロの扱い

- マクロの呼び出し行は命令として解釈できず，パース失敗として扱う
  - 命令を生成しない
  - パース失敗の警告が1件出る
- マクロ定義の本体は命令として配置しない
  - 定義の後ろにあるラベルのアドレスがずれない
- [ ] 要決定: 未対応のマクロを読み飛ばすか，読み込みをエラーにするか

### マクロ定義

- [ ] `.macro name` から `.end_macro` までを定義として記録し，命令を生成しない
- [ ] 呼び出し `name` が本体の命令列に展開される
- [ ] 引数付きの定義と呼び出しで，引数が置換される
- [ ] 展開後の命令数が後続のラベルのアドレスに反映される
- [ ] 次の場合はパース失敗(または読み込みエラー)になる
  - 未定義のマクロの呼び出し
  - 引数の数の不一致
  - `.end_macro` のない定義
- [ ] 要決定: 引数の書式(MARS 互換の `.macro name (%a, %b)` か)
- [ ] 要決定: 展開後の命令の `SourceLine` を呼び出し行にするか，本体の行にするか
- [ ] 要決定: 本体内のラベルを展開ごとに一意にする方法
- [ ] 要決定: 入れ子の定義と再帰呼び出しを許すか
- [ ] 要決定: 定義はファイル内のみ有効か

### .eqv

- [ ] `.eqv NAME, value` の後，即値やオペランドの `NAME` が `value` に置換される
- [ ] 未定義の名前はパース失敗になる
- [ ] 要決定: 区切りに `,` を必須とするか(MARS は `.eqv N 10` も受け付ける)
- [ ] 要決定: `.data` の値(`.word N`)にも適用するか

### .include

- [ ] `.include "file"` の位置にファイルの内容を挿入した場合と同じ結果になる
- [ ] 存在しないファイルは読み込みエラーになる
- [ ] 要決定: 相対パスの基準(インクルード元のファイルか作業ディレクトリか)
- [ ] 要決定: 挿入された行の `SourceLine` とファイルの対応
- [ ] 要決定: 循環インクルードの検出
