# 疑似命令展開の振る舞い

## 追加のパラメータ

- `li`
  - 即値: [values.md](../instructions/values.md) の32bit値(符号付き・符号なし)
  - 即値の表記
    - 10進
    - 16進
  - 16bit に収まる境界の内側と外側
  - 書き込み先が `$zero`
- `la`
  - ラベルの定義場所
    - データセグメント
    - テキストセグメント(前方・後方)
    - カーネルテキストセグメント
  - アドレスの下位16bitが0
  - `$` を含むラベル
- `move`
  - レジスタエイリアス
  - 書き込み先が `$zero`
  - 元の値: values.md のビットパターン
- `nop`
  - 大文字

## 追加の検証

### 共通

- 展開後の命令を順に実行すると，書き込み先レジスタが定義通りの値になる
  - 書き込み先の以前の値に依存しない
- 展開後の命令をすべて `undo` すると，実行前の状態に戻る
- 書き込み先が `$zero` でも，`$zero` は `0` のままである

### li

- 展開後の命令数
  - `[0, 65535]` は1命令
  - それ以外は2命令
- 結果は即値の32bit表現と一致する
  - 負の値は2の補数で表す
  - 同じ値の符号付き表記と符号なし表記は同じ結果になる

#### 異常系

- 次の場合はパースに失敗する
  - 符号付き・符号なしの32bitに収まらない値
  - ラベルの指定
  - オペランドの過不足
  - `$` のないレジスタ

### la

- 常に2命令に展開する．アドレスの下位16bitが0でも同じである
- 結果がラベルのアドレスと一致する
- 後方で定義するラベルも解決できる
- 別ファイルの `.globl` で宣言したラベルを解決できる
- `$` を含むラベルを解決できる
- [ ] ラベルとオフセット `la $t0, d+4`
- [ ] 要決定: アドレスの数値 `la $t0, 0x10000000` を受け付けるか

#### 異常系

- 次の場合は読み込みがエラー(`AssemblyException`)になる．命令数は2のままで，後続のラベルはずれない
  - 未定義のラベル
  - 別ファイルの `.globl` で宣言していないラベル
- オペランドの過不足はパースに失敗する

### move

- 1命令に展開する
- 結果は元のレジスタの値と一致し，元のレジスタは変化しない
- オーバーフロー例外を起こさない

#### 異常系

- 次の場合はパースに失敗する
  - レジスタでない第2オペランド
  - オペランドの過不足

### nop

- 1命令に展開する
- 実行しても状態が変化せず，命令自身は PC を設定しない
  - 汎用レジスタ
  - `HI`
  - `LO`
  - CP0
  - メモリ
- [x] 要決定: オペランド付きの `nop $t0` を失敗にするか (失敗にする)

### デバッガでの展開

- 2命令に展開された疑似命令は，`Step` を2回行うと実行が完了する
  - その間，現在行は疑似命令の行のまま変わらない
  - 次の `Step` で次の行に進む
- `Back` は1回につき展開後の1命令を戻す

### 未実装の疑似命令

[命令 対応状況チェックリスト](../../instructions.md) で未チェックの疑似命令はテストを免除する．

- 実命令と同じニーモニックの3オペランド形式(`div $t0, $t1, $t2` など)はパースに失敗する
