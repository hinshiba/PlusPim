# アセンブラ指令

アセンブラ指令の実装と仕様について．

## 対応状況

一般的にあると思われているアセンブラ指令と PlusPim 独自指令のリスト．

### セグメント

- [x] `.text`: テキストセグメント開始
- [x] `.data`: データセグメント開始
- [x] `.ktext`: カーネルテキストセグメント開始
- [-] `.kdata`: カーネルデータセグメント開始

### データ配置

これら指令はデータセグメントでなければ効果がありません．

- [x] `.byte`: バイト配置
- [x] `.half`: ハーフワード配置
- [x] `.word`: ワード配置
- [x] `.ascii`: ASCII範囲の文字列配置
- [x] `.asciiz`: ASCII範囲の文字列配置+自動NULL終端
- [x] `.utf-8z`: UTF-8エンコードの文字列配置+自動NULL終端
- [x] `.space`: 指定領域を確保
- [x] `.align`: アラインメント指定

### シンボル

- [x] `.globl`: グローバルシンボル宣言
- [x] `.global`: `.globl` の別名

### マクロ

- [-] `.macro`: マクロ定義開始
- [-] `.end_macro`: マクロ定義終了
- [-] `.eqv`: シンボル定数定義
- [-] `.include`: ファイルインクルード
- [-] `.extern`: 外部シンボル宣言

### オプション

- [-] `.set`: アセンブラオプション設定


## 仕様

現在は大文字と小文字を区別しませんが，将来的な仕様は保証しません．

### セグメント

- `.text`: テキストセグメント開始
- `.data`: データセグメント開始
- `.ktext`: カーネルテキストセグメント開始

現時点(v0.5.0)では引数を与えて指定したアドレスから配置を始める機能はサポートされていません．

将来的には検討されています．

### データ配置

#### バイナリ配置

- `.byte 42`
- `.half 0x42`
- `.word 0xffffffff`

すべてのバイナリ配置指令は指定された領域に収まらない場合にアセンブルエラーを生じます．

#### 文字列の配置

- `.ascii "your str"`
- `.asciiz "your str"`
- `.utf-8z "任意の文字列"`

ASCII 文字列の配置は ASCII 範囲でない文字が含まれる場合はアセンブルエラーを生じます．

すべての文字列配置指令は次のエスケープに対応します．
- `\n`: 改行
- `\t`: タブ文字
- `\0`: 終端文字
- `\\`: バックスラッシュ
- `\"`: ダブルクォーテーション

#### 領域の確保

- `.space 42`

指定された領域を確保します．
初期化は保証されません．

#### アライメント

- `.align 2`

2の"指定された引数"乗になるように追加の領域を確保します．

### シンボル

- `.globl label1, label2, ..., labeln`
- `.global label1, label2, ..., labeln`

ファイルを超えて解決するシンボルを指定します．

ファイル内に同名のシンボルがある場合は，そちらが優先されます．

同一のラベルを複数回指定した場合は，警告が生じ，最後のものが有効になります．
