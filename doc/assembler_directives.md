# アセンブラ指令

アセンブラ指令の実装と仕様について．

## 対応状況

一般的にあると思われているアセンブラ指令と PlusPim 独自指令のリスト．

### セグメント

- [x] `.text`: テキストセグメント開始
- [x] `.data`: データセグメント開始
- [x] `.ktext`: カーネルテキストセグメント開始
- [-] `.kdata`: カーネルデータセグメント開始

### データ配置

これら指令はデータセグメントでなければ効果がありません．

- [x] `.byte`: バイト配置
- [x] `.half`: ハーフワード配置
- [x] `.word`: ワード配置
- [x] `.ascii`: ASCII範囲の文字列配置
- [x] `.asciiz`: ASCII範囲の文字列配置+自動NULL終端
- [x] `.utf-8z`: UTF-8エンコードの文字列配置+自動NULL終端
- [x] `.space`: 指定領域を確保

### アラインメント・配置

- [x] `.align`: アラインメント指定
- [x] `.globl`: グローバルシンボル宣言
- [x] `.global`: `.globl` の別名

### マクロ・制御

- [-] `.macro`: マクロ定義開始
- [-] `.end_macro`: マクロ定義終了
- [-] `.eqv`: シンボル定数定義
- [-] `.include`: ファイルインクルード
- [-] `.set`: アセンブラオプション設定
- [-] `.extern`: 外部シンボル宣言

## 仕様

現在は大文字と小文字を区別しませんが，将来的な仕様は保証しません．

### データ配置

#### 文字列の配置

- `.ascii`
- `.asciiz`
- `.utf-8z`

ASCII 文字列の配置は ASCII 範囲でない文字が含まれる場合はアセンブルエラーを生じます．

すべての文字列配置指令は次のエスケープに対応します．
- `\n`: 改行
- `\t`: タブ文字
- `\0`: 終端文字
- `\\`: バックスラッシュ
- `\"`: ダブルクォーテーション
