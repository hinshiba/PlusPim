# アセンブラ

PlusPimのアセンブラの仕様を示します．

## 失敗時の挙動

アセンブラは警告とエラーの2種類の診断を出します．

- 警告 `PPW`: 決められた回復処理を行って続行します
- エラー `PPE`: 回復できず，アセンブルは失敗します

### コマンドライン引数 `--strict` がある場合

警告もすべてエラーとして扱い，警告が1つでもあればアセンブルは失敗します．

## 行の扱い

- `#` 以降はコメントとして除去します．文字列リテラルの中の `#` は除去しません．
- ニーモニック，アセンブラ指令，レジスタ名は小文字のみ受け付けます．
- ラベルは大文字と小文字を区別します．英字，`_`，`.`，`$` で始め，英数字，`_`，`.`，`$` を続けられます．レジスタ名と同じ綴りはレジスタとして読みます．

## セグメント

| 指令     | 開始アドレス |
| -------- | ------------ |
| `.text`  | `0x00400000` |
| `.ktext` | `0x80000180` |
| `.data`  | `0x10000000` |

- 最初の指令より前の行はテキストセグメントとして扱います
  - 警告を出力します
- 指令にアドレスを与えると，そのアドレスからセクションを配置します (`.text 0x00400100`)
  - テキストとカーネルテキストのアドレスは4の倍数でなければエラーとなります
  - セグメントの範囲に収まらないセクションと，重なるセクションはエラーとなります
- アドレスのない指令は，同じ種類の直前のセクションの末尾から続けます

## ラベル

- 同名のラベルは警告を出し，後の定義で上書きされます．
- 未定義ラベルの参照は警告を出し，アドレス `0x00000000` として解決します．
  - 分岐とジャンプは実行時に `0x00000000` へ飛びます
  - `la` は `0x00000000` を読み込みます
- グローバルな `main` がない場合は警告を出し，テキストセグメントの先頭から実行します．
- `.globl` か `.global` で宣言していないラベルは，別のファイルから参照できません．
- 分岐とジャンプは飛び先をアドレスのまま持つため，実機の範囲の制限 (分岐の±128KiB，ジャンプの256MiBの領域) を検査しません．

### レジスタ

- `$` に続けて名前 (`$zero`，`$at`，`$v0`-`$v1`，`$a0`-`$a3`，`$t0`-`$t9`，`$s0`-`$s7`，`$k0`-`$k1`，`$gp`，`$sp`，`$fp`，`$ra`) か番号 (`$0`-`$31`) を書きます
- 名前は小文字のみ受け付けます (`$T0` は不可)．番号は先頭に0を付けません (`$08` は不可)．`$32` 以上は不可です
- `mfc0`/`mtc0` の CP0 レジスタは番号 (`$0`-`$31`) のみ受け付けます．`$8`，`$12`，`$13`，`$14` 以外の番号は `OperandMismatch` (`PPW0012`) として行を捨てます．

## 複数ファイル

- ファイルは指定順に，セグメントごとに前のファイルの末尾から続けて配置します
- データセグメントは前のファイルの末尾から整列せずに続けます
  - ただし `.align` を含むセクションは，その最大のアラインメントに揃えた位置から始めます
- 複数のファイルが同じ名前を `.globl` で公開した場合は，警告を出して後のファイルの定義を用います
- 同じファイルを複数回指定した場合は，警告を出して2回目以降を無視します

## 診断の一覧

番号は削除等で欠番になることがあります．

### 警告

警告は `--strict` でない場合は回復処理を行い続行します．

| 警告番号    | 名前                   | 意味 | 回復処理                         |
| --------- | ---------------------- | - | -------------------------------- |
| `PPW0001` | `UnparsableLine`       | 行を構文として解釈できない                         | 行を捨てる                       |
| `PPW0002` | `UnknownMnemonic`      | 未知のニーモニックである                           | 行を捨てる                       |
| `PPW0003` | `UnknownDirective`     | 未知のアセンブラ指令である                         | 行を捨てる                       |
| `PPW0004` | `DiscardedOperand`     | 指令に不要なオペランドが与えられた                 | 指令の該当の値を捨てる           |
| `PPW0005` | `MissingSegment`       | 最初のセグメント指令より前に行がある               | テキストセクションとして扱う     |
| `PPW0006` | `MisplacedDirective`   | テキストセクションにデータ配置の指令がある         | テキストのデータ配置の指令を捨てる |
| `PPW0007` | `DuplicateLabel`       | 同名のラベルが再定義された                         | 後の定義で上書きする             |
| `PPW0008` | `UndefinedGlobal`      | `.globl` が未定義のラベルを指している              | `.globl` の宣言を捨てる          |
| `PPW0009` | `DuplicateGlobal`      | 複数のファイルが同じ名前を `.globl` で公開した     | 後のファイルの定義で上書きする   |
| `PPW0010` | `UndefinedSymbol`      | 未定義のラベルを参照した                           | アドレス 0 として解決する        |
| `PPW0011` | `MissingEntry`         | グローバルな `main` がない                         | テキストセグメントの先頭から開始 |
| `PPW0012` | `OperandMismatch`      | オペランドがニーモニックの形式に合わない           | 行を捨てる                       |
| `PPW0013` | `MisplacedInstruction` | データセクションに命令がある                       | データセクションの命令を捨てる   |
| `PPW0014` | `DuplicateSource`      | 同じソースが複数回指定された                       | 2回目以降の指定を捨てる          |

### エラー

エラーは回復不能の場合に発生します．

| エラー番号 | 名前                   | 意味                         |
| ---------- | ---------------------- | -------------------------------- |
| `PPE0001`  | `SourceNotFound`       | 指定されたソースが見つからない                     |
| `PPE0002`  | `ValueOutOfRange`      | 値が表現できる範囲に収まらない                     |
| `PPE0003`  | `NonAsciiString`       | 文字列にASCII以外の文字が含まれる                  |
| `PPE0004`  | `MisalignedText`       | テキストのアドレスが4の倍数でない                  |
| `PPE0005`  | `SectionOutOfRange`    | セクションがセグメントの範囲に収まらない           |
| `PPE0006`  | `SectionOverlap`       | セクションが別のセクションと重なる                 |
