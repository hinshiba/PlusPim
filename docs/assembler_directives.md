# アセンブラ指令

アセンブラ指令の実装と仕様について．

## 対応状況

一般的にあると思われているアセンブラ指令と PlusPim独自指令のリスト．

### セグメント

- [x] `.text`: テキストセグメント開始
- [x] `.data`: データセグメント開始
- [x] `.ktext`: カーネルテキストセグメント開始
- [-] `.kdata`: カーネルデータセグメント開始

### データ配置

これら指令はデータセグメントでなければ効果がありません．

- [x] `.byte`: バイト配置
- [x] `.half`: ハーフワード配置
- [x] `.word`: ワード配置
- [x] `.ascii`: ASCII範囲の文字列配置
- [x] `.asciiz`: ASCII範囲の文字列配置+自動NULL終端
- [x] `.utf-8z`: UTF-8エンコードの文字列配置+自動NULL終端
- [x] `.space`: 指定領域を確保
- [x] `.align`: アラインメント指定

### シンボル

- [x] `.globl`: グローバルシンボル宣言
- [x] `.global`: `.globl` の別名

### マクロ

- [-] `.macro`: マクロ定義開始
- [-] `.end_macro`: マクロ定義終了
- [-] `.eqv`: シンボル定数定義
- [-] `.include`: ファイルインクルード
- [-] `.extern`: 外部シンボル宣言

### オプション

- [-] `.set`: アセンブラオプション設定


## 仕様

現在は小文字のみ受け付けますが，将来的な仕様は保証しません．

### セグメント

- `.text`: テキストセグメント開始
- `.data`: データセグメント開始
- `.ktext`: カーネルテキストセグメント開始

- `.text 0x00400100`: 指定したアドレスからテキストセクションを始める

アドレスを与えると，そのアドレスから配置を始めます．
詳細は[アセンブラ](assembler.md#セグメント)を参照してください．

### データ配置

#### バイナリ配置

- `.byte 42`
- `.half 0x42`
- `.word 0xffffffff`

すべてのバイナリ配置指令は指定された領域に収まらない場合にアセンブルエラーを生じます．
整数でない値は警告を出して捨てます．

`.half` と `.word` は自動で整列しません．必要なら前に `.align` を置いてください．

#### 文字列の配置

- `.ascii "your str"`
- `.asciiz "your str"`
- `.utf-8z "任意の文字列"`

ASCII 文字列の配置は ASCII 範囲でない文字が含まれる場合はアセンブルエラーを生じます．

すべての文字列配置指令は次のエスケープに対応します．
- `\n`: 改行
- `\t`: タブ文字
- `\0`: 終端文字
- `\\`: バックスラッシュ
- `\"`: ダブルクォーテーション

#### 領域の確保

- `.space 42`

指定された領域を確保します．
初期化は保証されません．

#### アライメント

- `.align 2`

2の"指定された引数"乗の倍数のアドレスになるように追加の領域を確保します．
引数は0から30までです．

### ラベル

- `.globl label1, label2, ..., labeln`
- `.global label1, label2, ..., labeln`

ファイルを超えて解決するラベルを指定します．

ファイル内に同名のラベルがある場合は，そちらが優先されます．

同じファイルの中で同一のラベルを複数回指定しても，1回指定した場合と同じです．
複数のファイルで同一のラベルを指定した場合は，警告`DuplicateGlobal`(`PPW0009`)が生じます．
