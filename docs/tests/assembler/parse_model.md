# パースの振る舞い

## パラメータ

- 行の前処理
  - 行末のコメント
  - コメントのみの行
  - 空行
  - 文字列リテラル中の `#`
  - 改行コード
  - 空のファイル
- アセンブラ指令
- ラベル
  - インデント
  - `$` を含む
  - `:` の前の空白
  - 同名の重複
- 命令のオペランド
  - 区切り
  - レジスタの表記
  - 16bit 即値: [values.md](../instructions/values.md) の16bit値に加え，範囲の外側
  - シフト量: 範囲の内側と外側
  - メモリオペランドの書式
  - 分岐とジャンプのラベル
- データセグメント
  - 値を配置する
  - 文字列を配置する
    - 指令: `.ascii`，`.asciiz`，`.utf-8z`
    - 文字: ASCII のみ，ASCII 範囲外の文字(2バイトと4バイトの UTF-8 になるもの)を含む
    - エスケープ: 上記のすべて，未知のもの

## 検証

### 行の前処理

- コメントが無視される
- コメントのみの行と空行は命令もラベルも生成しない
  - 後続の `SourceLine` は行を数えた値のままである
- CRLF は LF と同じ結果になる
- 空のファイルは何も生成せず，警告も出ない

### セグメント

- 指令なしで始まるファイルはテキストとして扱い，警告が発生する
- 同じセグメントを再開すると，前回の続きに配置される

### ラベル

- インデントや `$` を含むラベルが登録される
- `:` の前に空白があるとラベルにならない
- 1行に複数のラベルを書くと，すべて同じアドレスになる
- 重複した定義は後のものが残り，警告が発生する

### 命令のオペランド

#### 正常系

- 区切りは `,` の直後の空白の有無によらず成功する
- レジスタは小文字の名前と `$0` から `$31` の番号で指定できる
- 16bit 即値は `[-32768, 65535]` の範囲で成功する
  - 次の表記を受け付ける
    - 10進(`+`/`-`)
    - 16進(`0x`/`0X`)
- シフト量は `[0, 31]` の範囲で成功する
- メモリオペランドのオフセットは次を受け付ける
  - 10進
  - 16進

#### 異常系

- `,` を省いた空白区切りは失敗する
- 範囲外の番号(`$32` など)と未知の名前は失敗する
- 16bit 即値の範囲外の値とラベルは失敗する
- シフト量の範囲外の値は失敗する
- テキストセグメント中の `.align` と `.word` は命令を生成せず，警告を発生させる
  - `--strict` ではエラーになる


### データ指令の値

- 値はリトルエンディアンで書かれる
- 複数の値は指定順に連続する
- `.space 0` は何も確保せず警告を発生させる
- `.ascii` は NUL を付けず，`.asciiz` と `.utf-8z` は NUL で終端する
  - `.ascii` と `.asciiz` は ASCII 範囲の文字だけを受け付ける
    - ASCII 範囲外の文字を含むとアセンブルエラーになる
      - `--strict` の有無によらず発生する
      - ファイル名と行番号を含む
      - その指令は何も配置しない
      - 複数あるとまとめて報告される
      - コメント中の ASCII 範囲外の文字は影響しない
    - エスケープの `\0` は ASCII 範囲の文字として受け付ける
  - `.utf-8z` は文字列を UTF-8 のバイト列で書く
    - ASCII 範囲外の文字は UTF-8 の多バイト列になる(サロゲートペアは4バイト)
    - 指令名の大文字と小文字は区別しない
    - 指令名の `-` がラベルの判定や行の分割に影響しない
    - 多バイトの文字列の後のラベルとアラインメントはバイト数で決まる
  - すべての文字列配置指令は次のエスケープを ASCII として解釈する
    - `\n`
    - `\t`
    - `\0`
    - `\\`
    - `\"`
  - 未知のエスケープは `\` と文字がそのまま書かれる
- 閉じる引用符がない文字列は警告を発生させる
- `.data` 中の命令は警告を発生させる
