# アセンブラテスト用パラメータリファレンス

入力種類ごとに代表値と境界値を示す．境界値は範囲の両端とその外側の隣接値である．

## ソースファイル

- 代表値: 1ファイル，2ファイル
- 境界値
  - 空のファイル
  - 同じファイルの2回の指定
  - 読めないファイル

## 行

- 代表値: 命令の行，ラベルだけの行
- 境界値
  - 行末のコメント，コメントのみの行，空行
  - 文字列中の `#`
  - 改行コード: LF，CRLF
  - セグメント指令より前の行

## 整数リテラル

すべての整数オペランドに共通する表記である．桁の間に区切りの `_` を置ける．絶対値が32bitを超える値は不正な表記として行を捨てる．

- 代表値: `42`，`+42`，`-42`，`0x2a`，`0X2A`，`-0x2a`，`4_2`
- 境界値
  - 絶対値: `4294967295`，`4294967296`，`-4294967295`，`-4294967296`，`0xffffffff`，`0x100000000`
  - 桁区切りの位置: `1_0`，`42_`，`0x_2a`
  - 不正な表記: `0x`，`-`，`0x1g`

上限が `4294967295` の範囲では，上側の外側の隣接値 `4294967296` を整数リテラルの絶対値で先に拒否する．そのような範囲の上側の外側は整数リテラルの境界値で検査する．

## ニーモニック

各ニーモニックの代表値を示す．即値の拡張方式は括弧内に示す．

| ニーモニック                                                    | 代表値                    |
| --------------------------------------------------------------- | ------------------------- |
| `add`，`addu`，`sub`，`subu`，`and`，`or`，`xor`，`nor`，`slt`，`sltu` | `add $t0, $t1, $t2`       |
| `sllv`，`srlv`，`srav`                                          | `sllv $t0, $t1, $t2`      |
| `addi`，`addiu`，`slti`，`sltiu` (符号拡張)                     | `addi $t0, $t1, -1`       |
| `andi`，`ori`，`xori` (ゼロ拡張)                                | `andi $t0, $t1, 0xffff`   |
| `sll`，`srl`，`sra` (シフト量)                                  | `sll $t0, $t1, 4`         |
| `lui`                                                           | `lui $t0, 0x1000`         |
| `beq`，`bne`                                                    | `beq $t0, $t1, label`     |
| `bgez`，`bgtz`，`blez`，`bltz`                                  | `bgez $t0, label`         |
| `j`，`jal`                                                      | `j label`                 |
| `jr`                                                            | `jr $ra`                  |
| `jalr`                                                          | `jalr $t0`，`jalr $t1, $t0` |
| `mult`，`multu`，`div`，`divu`                                  | `mult $t0, $t1`           |
| `mfhi`，`mflo`，`mthi`，`mtlo`                                  | `mfhi $t0`                |
| `lb`，`lbu`，`lh`，`lhu`，`lw`，`lwl`，`lwr`                    | `lw $t0, 4($sp)`          |
| `sb`，`sh`，`sw`，`swl`，`swr`                                  | `sw $t0, 4($sp)`          |
| `mfc0`，`mtc0`                                                  | `mfc0 $t0, $12`           |
| `syscall`，`break`，`eret`，`runtime_call!`                     | `syscall`                 |
| `nop`                                                           | `nop`                     |
| `move`                                                          | `move $t0, $t1`           |
| `li`                                                            | `li $t0, 0x000cafe0`      |
| `la`                                                            | `la $t0, label`           |

- 境界値
  - 未知のニーモニック: `foo`
  - 大文字: `ADD`
  - 末尾の `!`: `runtime_call`，`add!`
  - オペランドの過不足: `add $t0, $t1`，`add $t0, $t1, $t2, $t3`，`syscall $t0`
  - オペランドの種類違い: `add $t0, $t1, 1`，`addi $t0, $t1, $t2`，`j $t0`
  - CP0 レジスタ番号: `$8`，`$12`，`$13`，`$14` は受理，`$0`，`$31` は拒否
  - CP0 レジスタの名前による指定: `$t4`
  - テキスト以外での命令: `.data` 中の `nop`

## オペランドの区切り

- 代表値: `add $t0, $t1, $t2`，`add $t0,$t1,$t2`
- 境界値: `add $t0 $t1 $t2`，`add $t0, $t1, $t2,`，`add , $t0, $t1, $t2`

## 命令のオペランド

### 16bit即値

範囲は `[-32768, 65535]` である．符号の解釈は命令が選ぶ．

- 代表値: `0`，`0x0afe`，`-1`
- 境界値: `-32769`，`-32768`，`65535`，`65536`

### シフト量

範囲は `[0, 31]` である．

- 代表値: `1`，`16`
- 境界値: `-1`，`0`，`31`，`32`

### メモリオペランド

オフセットの範囲は16bit即値と同じである．

- 代表値: `4($sp)`，`-4($sp)`，`0x10($t0)`，`($t0)`，`4 ( $t0 )`
- 境界値: `-32769($t0)`，`-32768($t0)`，`65535($t0)`，`65536($t0)`
- 不正な書式: `4($t0`，`4(label)`，`label($t0)`

### レジスタ

- 代表値: `$t0`，`$8`，`$zero`，`$ra`
- 境界値: `$0`，`$31`，`$32`，`$08`，`$T0`，`$t10`，`$s8`

### ラベル参照

- 代表値: 前方ラベル，後方ラベル，命令自身のラベル
- 境界値: 未定義ラベル，別ファイルの `.globl` ラベル，別ファイルの非公開ラベル

## 疑似命令

### `li` の即値

範囲は `[-2147483648, 4294967295]` である．`[0, 65535]` は1命令，それ以外は2命令に展開する．

- 代表値: `0x000cafe0`，`-0x7ff45420`，`0`
- 境界値
  - 範囲: `-2147483649`，`-2147483648`，`4294967295`
  - 展開の命令数: `-1`，`0`，`65535`，`65536`
  - 下位16bitが0: `0x00010000`，`0xffff0000`

## データ配置指令

### 整数値

| 指令    | 範囲                          |
| ------- | ----------------------------- |
| `.byte` | `[-128, 255]`                 |
| `.half` | `[-32768, 65535]`             |
| `.word` | `[-2147483648, 4294967295]`   |

- 代表値: `0`，`1`，`-1`，複数の値(`1, 2, 3`)
- 境界値: 各範囲の下限と上限，およびその外側の隣接値 (`.word` の上側の外側を除く)
- 整数でない値: ラベル，文字列
- 配置先: テキストセクション中の `.word`

### `.space`

範囲は `[0, 2147483647]` である．

- 代表値: `1`，`4`，`42`
- 境界値: `-1`，`0`，データセグメントの残りちょうど，残り+1

### `.align`

範囲は `[0, 30]` である．

- 代表値: `2`
- 境界値: `-1`，`0`，`30`，`31`
- 整列前の位置: 境界ちょうど，境界+1，境界-1

### 文字列

指令は `.ascii`，`.asciiz`，`.utf-8z` である．

- 代表値: `"abc"`，`""`
- ASCII の境界: `\x7f` の文字 (1バイト)，`U+0080` (2バイト)
- UTF-8 のバイト数の境界: `U+07FF` (2バイト)，`U+0800` (3バイト)，`U+FFFF` (3バイト)，`U+10000` (4バイト，サロゲートペア)
- 孤立サロゲート
- エスケープ: `\n`，`\t`，`\0`，`\\`，`\"`，未知(`\a`)，行末の `\`
- 文字列中の `#` と `,`
- 閉じる引用符がない文字列

## 指令名

- 代表値: [アセンブラ指令](../../assembler_directives.md)の各指令
- 境界値: 未知の指令(`.foo`)，大文字(`.TEXT`)，別名(`.global`)

## `.globl`

- 代表値: `.globl main`，`.globl a, b`
- 境界値
  - 整数と文字列: `.globl 1`
  - ファイル内で未定義の名前
  - 複数のファイルが同じ名前を公開する

## エントリ

- 代表値: `.globl main` で公開した `main`
- 境界値: 公開しない `main`，`main` がない

## セグメント指令のアドレス

範囲は `[0, 4294967295]` である．テキストとカーネルテキストは4の倍数に限る．

| セグメント | 配置できる範囲                 |
| ---------- | ------------------------------ |
| `.text`    | `[0x00400000, 0x10000000)`     |
| `.data`    | `[0x10000000, 0x80000000)`     |
| `.ktext`   | `[0x80000000, 0x90000000)`     |

- 代表値: アドレスなし，同じセグメントの再開，`.text 0x00400100`，`.data 0x10000100`
- 境界値
  - 範囲: `-1`，`0`，`0xffffffff`
  - セグメントの範囲: 下限，下限-1，上限ちょうどで終わるセクション，上限を1超えるセクション
  - アラインメント: 下位2bitが `00`，`01`，`10`，`11`
  - 重なり: 前のセクションの末尾ちょうど，末尾-1

## ラベル定義

- 代表値: `main`，`_loop`，`.L1`，`a$b`
- 境界値
  - 先頭の文字: `_`，`.`，`$`，数字(`1abc`)
  - レジスタと同じ綴り: `$t0`，`$31`，`$32`
  - 大文字と小文字だけ異なる名前: `Loop` と `loop`
  - `:` の前の空白: `label :`
  - 1行に複数: `a: b: c:`
  - 同じ名前の再定義
