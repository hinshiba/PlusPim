# 疑似命令展開の振る舞い

## 検証

### 共通

- 展開後の命令を順に実行すると，書き込み先レジスタが定義通りの値になる
  - 書き込み先の以前の値に依存しない
- 展開後の命令をすべて `undo` すると，実行前の状態に戻る
- オペランドの過不足はパースに失敗する

### li

- 展開後の命令数
  - `[0, 65535]` は1命令
  - それ以外は2命令
- 結果は即値の32bit表現と一致する

#### 異常系

- 次の場合はパースに失敗する
  - 符号付き・符号なしの32bitに収まらない値
  - ラベルの指定

### la

- 常に2命令に展開する．アドレスの下位16bitが0でも同じである
- 結果がラベルのアドレスと一致する
- 後方で定義するラベルも解決できる
- 別ファイルの `.globl` で宣言したラベルを解決できる

#### 異常系

- 次の場合は読み込みがエラー(`AssemblyException`)になる．
  - 未定義のラベル
  - 別ファイルの `.globl` で宣言していないラベル

### move

- 1命令に展開する
- 結果は元のレジスタの値と一致し，元のレジスタは変化しない
- オーバーフロー例外を起こさない

### nop

- 1命令に展開する

### デバッガでの展開

- 2命令に展開された疑似命令は，`Step` を2回行うと実行が完了する
  - その間，現在行は疑似命令の行のまま変わらない
  - 次の `Step` で次の行に進む
- `Back` は1回につき展開後の1命令を戻す
