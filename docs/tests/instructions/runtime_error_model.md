# ランタイムエラーの振る舞い

## 追加の検証

- 命令が起こすランタイムエラーは，カーネルモードでも二重例外にならない
- ランタイムエラーの後は `StepBack` で実行前の状態に戻る

## 命令の無いアドレスの実行

- データセグメント，テキストの末尾より後，カーネルテキストのハンドラが無い例外ベクタを実行すると `NonInstructionExecution` になる
- カーネルモードでも `NonInstructionExecution` であり，二重例外にならない
- 次は `AdEL` 例外のままである
  - ユーザーモードでのカーネルテキストの実行
  - セグメント外(`0x00000000`，`0x90000000`)の実行
  - 4の倍数でないアドレスの実行

## テキストの読み書き

- テキストとカーネルテキストの先頭と末尾のアドレスへのロード，ストアは `TextAccess` になる
- データセグメントの末尾(`0x7FFFFFFC`)へのロード，ストアは成功する
