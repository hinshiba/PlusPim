# 履歴の振る舞い

`Timeline` は実行した位置の列の上を前後に動く．
実行は決定的なので，位置 p の状態は「初期状態から履歴なしで p ステップ進めた状態」と一致しなければならない．
テストはこの参照を `Debuggee` で作り，`Timeline` をどの経路で動かしても参照と一致することを確かめる．

状態の比較はレジスタ，コールスタック，`Status`，プログラムが書き込むメモリで行う．
チェックポイントの間隔は公開しないので，プログラムは十分に長くして区間の境界を何度もまたがせる．

## 検証する事項

- 前進: 1ステップごとに参照と一致する．停止した位置では判定を呼び，位置は変わらない
- 後退: 1ステップごとに参照と一致し，位置0で `Start` を返す
- 判定つきの後退 (ReverseContinue): 現在位置より前で判定が値を返す最後の位置で止まる．なければ位置0まで戻って `Start`
- 判定つきの前進 (Continue): 現在位置より後で判定が値を返す最初の位置で止まる
- 任意の順の前後の移動: 移った先は常に参照と一致する
- 出力: 位置ごとに一度だけ書かれ，戻ってから再び進んでも繰り返さない
- 入力: 入力が足りなければ `NeedInput` を返して位置を変えない．戻って再び進むときは同じ入力を読み，`NeedInput` にならない
