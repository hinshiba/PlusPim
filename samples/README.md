# サンプル

動作確認用のMIPSアセンブリ．
同じプログラムを[遅延スロット](../docs/runtime.md#遅延スロット)の有無で2つのディレクトリに分けている．

| ディレクトリ      | 起動のオプション                              |
| ----------------- | --------------------------------------------- |
| `delay-slots/`    | なし                                          |
| `no-delay-slots/` | `--no-delayed-branches`，`--no-delayed-loads` |

`syscall`を使うので，同じディレクトリの`kseg.asm`を一緒に読み込む．
このディレクトリをVS Codeで開くと，`.vscode/launch.json`の`Delay Slots`と`No Delay Slots`で開いているファイルを起動できる．

## 遅延スロットの埋め方

`delay-slots/`では，遅延スロットに前後の命令を移して`nop`を減らしている．

- 分岐の遅延スロットには，分岐の成立と不成立のどちらで実行しても正しい命令を置く
- `jal`は遅延スロットの前に`$ra`を書き換えるので，`$ra`の退避は`jal`の前に置く
- `li`と`la`は`lui`と`ori`の2命令に展開されるため，遅延スロットに置けない．小さな即値は`addiu $a0, $zero, 10`のように書く
- 関数の最後の呼び出しは，`$ra`を復元してから`j`で飛ぶ末尾呼び出しにして，戻り先を呼び出し元に直接つなぐ
- 置ける命令がない遅延スロットにだけ`nop`を残す

各サンプルの出力は`tests/PlusPim.Dbg.Tests/SampleTests.cs`で両方のモードについて検査している．
